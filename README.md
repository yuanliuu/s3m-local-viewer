# 🌍 S3M Local Viewer

本地 [S3M](https://github.com/SuperMap/s3m-spec) 三维模型文件预览工具。

## 📦 功能特性

- [x] 支持本地 `.s3mb` 文件数据结构展示和模型预览
- [x] 支持无索引文件下的多瓦片加载
- [x] 索引文件规范错误提示（部分）
- [ ] 模型纹理预览

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 构建生产版本

```bash
npm run build
```

### 使用说明

1. 打开应用页面（`dist/index.html`）。
2. 选择一个或多个 `.s3mb` 文件。
3. 等待加载完成后即可查看三维模型。
4. 支持缩放、旋转、平移等交互操作。

\* 注意：需通过 WEB 服务器访问，避免浏览器安全限制。
